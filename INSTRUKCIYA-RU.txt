ИНСТРУКЦИЯ — САЙТ GRAND MOBILE HORRORS
======================================

Это полный исходный код вашего сайта. Из него можно запустить сайт
у себя и получить свою собственную ссылку (например, на своём домене).

ЧТО НУЖНО УСТАНОВИТЬ
--------------------
1. Bun (или Node.js 20+) — https://bun.sh
   Windows: скачайте установщик с сайта bun.sh и запустите его.

КАК ЗАПУСТИТЬ САЙТ НА СВОЁМ КОМПЬЮТЕРЕ
--------------------------------------
1. Откройте папку grand-mobile-horrors в терминале (командной строке).
2. Выполните:
       bun install
3. Затем:
       bun run dev
4. Откройте в браузере адрес, который покажет терминал
   (обычно http://localhost:3000).

КАК ВЫЛОЖИТЬ В ИНТЕРНЕТ (сделать свою ссылку)
---------------------------------------------
Вариант А. Бесплатный хостинг Vercel (проще всего):
1. Зарегистрируйтесь на https://vercel.com
2. Загрузите эту папку (можно через GitHub: создайте репозиторий,
   залейте файлы, затем в Vercel нажмите "Add New Project" и выберите его).
3. Vercel сам определит настройки. Framework preset: Vite.
4. Нажмите Deploy — вы получите ссылку вида имя.vercel.app.

Вариант Б. Netlify (https://netlify.com) — аналогично, через GitHub.

Вариант В. Свой сервер / VPS:
   bun install
   bun run build
   и запустите собранный сервер из папки dist (см. документацию
   TanStack Start: https://tanstack.com/start).

СВОЙ ДОМЕН (например grandmobilehorrorsfamily.com)
--------------------------------------------------
1. Купите домен у любого регистратора (reg.ru, namecheap и т.п.).
2. В настройках хостинга (Vercel/Netlify) добавьте домен в проект
   и укажите DNS-записи, которые он попросит.

ГДЕ МЕНЯТЬ ССЫЛКИ НА САЙТЕ
--------------------------
Файл: src/config/links.ts

  TELEGRAM_GROUP_URL   — ссылка на Telegram-группу HORRORS
                         (кнопки «ВСТУПИТЬ В ГРУППУ» и «Перейти в группу»).
                         Сейчас пустая: кнопки ведут на личный контакт.
  TELEGRAM_CONTACT_URL — личный контакт @awarano (уже заполнено).
  MUSIC_URL            — ссылка на mp3-файл с музыкой (можно оставить пустой).

После изменения файла перезапустите сайт (или снова опубликуйте).
